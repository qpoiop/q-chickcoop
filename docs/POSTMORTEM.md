# 실패한 3D 액션 게임 프로젝트 회고

한 웹 기반 3D 트윈스틱 액션 로그라이트 프로토타입의 실패 기록. 약 2일, 200+ 커밋을
쏟았지만 **체감 퀄리티는 처음과 끝이 동일**했다. 다음 프로젝트가 같은 함정을 반복하지
않도록 증거 기반으로 남긴다. (구체 실행 지침은 `NEXT_GAME_GUIDE.md`.)

---

## 1. 무슨 일이 있었나 (증상, 커밋 실측)

- **2일에 200+ 커밋.** 메인 게임 파일이 **70회+**, 레벨 데이터가 **45회+** 수정됨.
- **같은 문제를 각각 10~25회 재수정**: 맵/스폰/배치/밝기/워크블/오클루전. 진전이 아니라
  같은 지점을 계속 터뜨리고 다시 막는 반복.
- **플레이 맵을 통째로 3번 갈아엎음.**
- **아트 에셋 커밋 6개(전부 다운로드) vs 코드 커밋 90개.**

## 2. 왜 퀄리티가 안 변했나

- **3D 게임 체감 퀄리티의 ~80%는 아트·손맛(모델/애니/VFX/라이팅/일관성).** 그 레이어를
  단 한 번도 제대로 안 건드림.
- 에셋이 전부 **짝 안 맞는 다운로드 립** — 컨셉과 무관한 밈/잡동사니 텍스처까지 혼입.
  비주얼 천장이 여기서 고정됐고, 코드를 200번 커밋해도 그 천장은 안 움직였다.
- 무기 여러 종이 **수치만 다르고 손맛(반동/히트스톱/파티클/사운드)이 동일**.
- **캐릭터=잡몹=보스가 같은 모델** → 난전 가독성 0.

### 2-1. 더 깊은 문제 — 전투 "설계" 자체가 지루했다 (아트/juice로 못 덮음)

퀄리티(아트) 이전에, **전투 메카닉이 애초에 흥미가 없었다.** 이건 이펙트로 못 고친다.

- **자동조준** → 조준 스킬 자체가 없음. 실력 표현 0.
- **적이 다 "걸어오는 동일 개체"** → 대응이 한 가지(뒤로 빼며 쏘기). 매 순간 판단이 없음.
- **무기가 수치만 다름** → 플레이 방식이 안 바뀜.
- **포지셔닝·리스크·빌드 시너지**가 결정 축이 아님.

→ **매 순간 다른 판단**이 없는 루프. juice(히트스톱/파티클)를 아무리 발라도 "반짝이는
지루함". **재미의 실체는 전투 설계(판단·역할·전술·간격·리스크)인데 그걸 안 짰다.**

## 3. 4대 근본 원인

1. **증상만 반복, 근본 회피.** 근본은 "감상용 씬을 플레이맵으로 쓴 것 + 짝 안 맞는 에셋".
   이걸 안 건드리니 밴드에이드가 매번 재발 → 결국 맵 3번 재작성.
2. **성공 관문을 잘못 잡음.** "빌드 통과 + 배포 성공 + 앵커가 걷는 땅 위"를 성공으로 침.
   정작 관문이어야 할 **"전투가 재밌나 / 통일감 있나"** 를 한 번도 게이트로 안 씀.
3. **짧은 자동 반복 루프가 실패를 구조화.** "일정 주기마다 머지 가능한 뭔가"를 강제하면,
   그 시간 안에 되는 건 항상 **제일 작은 변경(값 튜닝/버그픽스/리팩터)**뿐. 아트·손맛·재설계
   같은 "짧게 못 끝내는 진짜 일"을 루프가 구조적으로 회피 → 움직임 200, 퀄리티 델타 0.
4. **후반 코드-청소 도피.** 상수 정리·죽은코드 제거·문서 다수. 체감 퀄리티 영향 0인데
   "진도 나가는 척" 하기 좋음.

## 4. 코드 구조도 근본이 틀렸다

- **갓-오브젝트 모놀리스**: 한 클래스(2000줄)가 상태·전투·렌더·입력·UI·스폰·AI를 전부 소유.
  전부 서로 직접 참조 → 하나 건드리면 다 흔들림. 그래서 증상만 200번 두들겼다.
- **엔티티 = 타입 없는 속성 주머니.**
- **동작이 데이터가 아님**(값만 설정 분리, 로직은 한 파일) → 시스템 단위 교체·테스트 불가.
- **UI가 게임 로직에 결합**, **상태머신 없음**(불리언 난립), **시드 RNG 없음**(런 재현 불가),
  **렌더 파이프라인 애드혹**(블룸/톤매핑 함정에 반복해서 물림).

## 5. 한 줄 결론

> **짝 안 맞는 공짜 에셋 위에서, 퀄리티를 결정하는 축(아트·손맛·구조)은 손도 안 대고,
> 증상만 200번 두들기며 "배포됨"을 성공으로 착각한 것.** 퀄리티가 안 변한 건 필연이었다.

## 6. 다음 프로젝트가 반드시 가져갈 것

1. **에셋·손맛부터.** 통일된 리그드 캐릭터+무기, 손맛 나는 전투 한 방을 먼저.
2. **성공 관문 = "재밌나 / 좋아 보이나".** 빌드·배포는 성공이 아니라 전제조건.
3. **시스템 경계 있는 아키텍처**부터. 갓-오브젝트 금지.
4. **근본을 고쳐라.** 같은 증상 2번째 손대면 멈추고 구조를 의심.
5. **짧은 "뭐라도 커밋" 루프 금지.** 진짜 일에 며칠을 통으로 써라.
