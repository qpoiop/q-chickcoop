  bare `Ground_Sol` 벌판, 그 위에 아무것도 없어 파란 하늘색 반구광만 받아 파랗게
  보임 + 평평/walkable이라 걸어나가짐. 근본 원인 확인.
  - 수정: `_finishMapLoad`에 **국소 워크블 밀도 트림**(`mapFit.trimOpen`) 추가 —
    R4 창에서 밀도>임계(숲 0.9)인 "너무 열린" 셀=빈 벌판을 walkable에서 제거.
    나무로 쪼개진 콘텐츠는 살아남음. 숲만 opt-in.
  - 결과: 서쪽 직진 이동 -45→-16 차단, 코어A(Temple) 유지, 도달 760셀 유지.
  - **잔여**: 벌판 가장자리는 북쪽 우회로로 여전히 일부 접근 가능. 임계/방향별
    경계 정교화, city/waterfall도 검증 후 opt-in 필요.

  해야 함. 안 하면 배치 다 어긋남. (MAP_GUIDE 4절)
- [x] **코어 B / 포탈이 안 보이는 곳에 배치됨** — probe 검증 완료: 코어 B (18,-6)
