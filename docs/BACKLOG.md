# 백로그 / 알려진 이슈

우선순위·상태를 여기서 관리한다. 고치면 체크. 근본 원인은 `ARCHITECTURE.md`.

## 🔴 열림 — 구조적 (신중히)

- [ ] **파란 void로 걸어나감** — 워크블 그리드가 어두운 물/평지(y≈0)를 걸을 수
  있다고 표시. 근본: 걸을 수 있는 영역을 **스폰에서 도달 가능한 연결 성분 +
  실제 콘텐츠 범위**로 제한해야. bounds만 조이면 비대칭 맵에서 한쪽은 여전히 샘.
- [ ] **맵 좌로 90도 회전** — `mapFit.yaw`를 넣되 **앵커 좌표도 같은 각도로 회전**
  해야 함. 안 하면 배치 다 어긋남. (MAP_GUIDE 4절)
- [ ] **코어 B / 포탈이 안 보이는 곳에 배치됨** — 코어 A는 잘 렌더됨 → 코드가
  아니라 **좌표가 void/어두운 가장자리**. probe 검증으로 밝은 곳에 재배치.
- [ ] **배치 신뢰성 일반화** — 하드코딩 앵커 대신 로드 시 실제 지형/구조물에서
  좋은 지점을 산출하는 방식 고려(반복되는 "안 보임"의 근본 해결).
